# BrewBudget
A lightweight, installable coffee-price comparison web app centered on 100 Northern Avenue, Boston.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `brewbudget`.
2. Upload `index.html`, `app.js`, `manifest.webmanifest`, `icon.svg`, and `sw.js` to the **root** of the repository (not inside an extra folder).
3. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/(root)`. Save.
4. Visit `https://YOUR-USERNAME.github.io/brewbudget/` after deployment.
5. On iPhone, open the URL in Safari, then choose **Share → Add to Home Screen**.

Prices are manually entered and stored locally on each device. This version does not query Google Places or retrieve live menu prices. Shop addresses and distance estimates are starter data, not verified live results.
